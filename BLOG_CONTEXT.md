# Blog Context

This repository is Wang Zizhe's personal static blog. Keep changes simple, explicit, and close to the existing HTML/CSS/JS structure.

## Project Structure

- `index.html`: Chinese homepage.
- `en/index.html`: English homepage.
- `posts.js`: Canonical bilingual post list for homepage rendering.
- `content/posts/*.html`: Canonical article body fragments.
- `templates/post.html`: Shared shell for every generated article page.
- `blog-index.js`: Progressive enhancement for the homepage hero typewriter effect.
- `scripts/build.mjs`: Validates post data and generates homepage cards, SEO metadata, sitemap, and RSS feeds.
- `styles.css`: Shared visual styles for homepages and post pages.
- `theme-toggle.js`: Generates and controls the light/dark theme buttons.
- `post-share.js`: Generates and wires post share buttons.
- `posts/*.html`: Generated Chinese and English article pages; do not edit directly.

## Homepage Rules

- Do not hand-code post cards in `index.html` or `en/index.html`; run `npm run build`.
- Add or update homepage post metadata in `posts.js`.
- Keep `posts.js` ordered newest first.
- Each post entry should include:
  - `date`
  - `zh.title`, `zh.href`
  - `en.title`, `en.href`
  - optional `zh.summary`, `en.summary`
- Use hrefs relative to the site root, for example `posts/2026-08-02-example.html`.
- `scripts/build.mjs` handles the `../` prefix for the English homepage.

## Post Page Rules

- Each post usually has two files:
  - Chinese: `posts/YYYY-MM-DD-slug.html`
  - English: `posts/YYYY-MM-DD-slug-en.html`
- Write正文 in the matching `content/posts/*.html` source fragment.
- Update metadata and bilingual pairing in `posts.js`.
- Run `npm run build`; never hand-edit generated files under `posts/`.
- Canonical, hreflang, navigation, footer, theme controls, and sharing are generated from `templates/post.html`.

## Header Controls

- Theme buttons are generated by `theme-toggle.js`; keep only:

```html
<div class="theme-switch" aria-label="Theme switcher"></div>
```

- Language buttons on detail pages remain explicit links to the paired post page.
- Homepage language switching is handled by `blog-index.js`.
- Current visual behavior: hide the active option, so the UI shows the action the user can switch to.

## Footer

- Keep footer text consistent across Chinese and English pages.
- The copyright symbol sizing fix is in `styles.css`; avoid page-specific footer overrides.

## Commit Preferences

- The user often asks for historical commit dates.
- Use `GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE` when committing with a requested date/time.
- Timezone is usually Europe/Berlin/CET unless the user says otherwise.
- Do not commit unless the user explicitly asks.

## Validation Checklist

Run this before reporting completion when code changes are non-trivial:

```bash
npm run check
git diff --check
```

The check dynamically validates post count, ordering, bilingual pairs, generated files,
local links, and JavaScript syntax. GitHub Actions runs the same command on pushes and
pull requests.
