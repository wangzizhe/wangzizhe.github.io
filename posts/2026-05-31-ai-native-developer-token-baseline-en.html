6 Billion Tokens a Month: A Baseline for AI-Native Developers

Codex's update this Friday finally added token usage stats.

I remember reading that Anthropic employees use around 5B tokens per month on average, which is roughly 250M per day. I've always been curious what "normal" token usage looks like for a peer at an AI-native startup.

Now I finally have my own data point: I used 6B tokens on Codex (GPT-5.5) alone in May. Over 30 working days, that's about 200M tokens per day. On top of that, I also use DeepSeek V4 and Kimi K2.6 (I don't use OpenClaw).

The best part? I optimized the setup enough to run those 6B tokens for just 51 Euros. That's about 120M tokens for a single Euro. It wasn't easy to get the cost down to this level, but it was definitely fun!

I think this is pretty close to what a full-time developer in an AI-native startup actually uses. 5B tokens a month feels completely average. If a full-time developer in an AI-native startup uses less than 100M tokens a day, there's probably something wrong.
