第一次参加黑客松

这周末，我参加了人生中的第一次黑客松。过去我对黑客松一直不太感兴趣，因为我总觉得自己的编程能力不够好，很难真正把一个想法实现出来。但最近几年，随着好奇心越来越强，再加上 AI 智能体的帮助，我发现自己已经不需要把太多精力放在“具体怎么实现”上，而是可以更多地思考问题本身：这个问题是否真实存在，市场上已经有哪些解决方案，用户真正的痛点是什么，以及我可以从哪个细分点切入。除此之外，我也想通过黑客松快速学习新东西。和来自不同国家、拥有不同背景的人一起参与，可以让我看到其他人是如何思考问题的，也能帮助我更清楚地认识自己的优势和不足。而且我相信，喜欢参加黑客松的人，大多也是一群好奇心强、善于探索的人。即使最后没有获奖，能够认识一些有趣的人，本身也已经很有价值。更何况活动是在周末举行，不占用平时的时间，怎么看都很划算。

于是我报名了。不过一开始，我并没有认真想过要获奖。毕竟是第一次参加，我主要是想了解一下黑客松的完整流程，顺便领取一些免费的 API 使用额度，用来开发自己的项目。我选择参加德累斯顿的线下会场。周六下午三点，我来到了位于德累斯顿的活动场地 YETI。下午六点，各地的线下会场和线上参与者通过 Zoom 连线，参加统一的启动会。但不得不说，这部分极其无聊。整个启动会持续了大约 50 分钟，除了最后两页内容之外，几乎没有什么真正有用的信息。除了一开始各个会场轮流打招呼，剩下的大部分时间基本都是赞助商的广告。第一位演讲嘉宾是 Maschmeyer Group 的首席执行官，播放的是一段提前录制的视频，但视频效果实在太差了，不知道是谁剪辑的，看起来完全像是 AI 生成的。诚恳地说，甚至还不如现在很多 AI 生成的视频。后面的内容我基本没怎么听进去，不仅没有太多营养，其中一个会场的麦克风效果还非常差，听他们讲话简直是一种折磨。直到晚上 6:50，主办方终于开始公布挑战题目，这大概是整个一小时环节中唯一真正有意义的十分钟。题目公布之后，接下来便是 20 个小时的开发时间，所有队伍需要在周日下午三点之前完成并提交项目。然后，黑客松正式开始了。而我在拿到价值 50 美元的 OpenAI API 使用额度之后，和现场的人聊了一会儿天，就直接回家了。

第二天起床之后，我认真想了一下。原本我的计划是，这次先了解流程，等到十月份再找一个黑客松认真参加。但转念一想，既然名都报了，为什么不真正参与一次呢？虽然距离提交截止时间只剩下五个小时，但五个小时就五个小时，能做出什么就做出什么。至少，真正完成一次项目之后，我才能更深入地理解黑客松的流程，也能更准确地分析自己和其他参与者之间的差距。于是，我从六个挑战题目中选择了最感兴趣的一个，也就是第二个题目：如何更快、更准确地发现有潜力的创业者，并对他们进行投资。我觉得这个题目很有意思，因为它给了我一个机会，让我可以换一个视角，以投资人的身份重新审视自己。

到了下午 2:30，我基本完成了项目，但还需要录制三个不同的视频。等视频全部录完，已经是 2:50。我开始提交项目，结果发现还需要填写很多问题，比如市场缺口是什么、目标用户是谁、产品的独特卖点是什么等等。全部填完时已经是 2:58，我点击提交，系统却提醒我必须先完善个人资料。我赶紧去补充资料，完成后一看时间已经是 2:59，于是立刻点击提交。幸运的是，最终提交成功了。

接下来就等一周后的结果，看看其他参与者都做了什么，也跟着优秀的人学习一下。另外，我还发现，这 50 美元的 OpenAI API 使用额度，大概让我使用了 5000 万个 Token。按照我平时每天使用 2 亿个 Token 来计算，如果全部通过 API 调用，我一个月大概要花 6000 美元。这样看来，OpenAI 在我身上确实很难赚到钱。

总的来说，这是一次很不错的体验。不过下次我大概会选择完全线上参加。这样既可以省掉一开始那一个小时意义不大的启动会，在家里的工作环境也更适合自己，更容易保持专注，而且完全没有必要熬夜不睡觉。我觉得参加黑客松最好的状态，就是该吃吃、该睡睡，把它当成一种乐趣，学习新东西，接触新事物，发现自己的优势和不足，而不是单纯把它当成一场比赛。
